# Portfolio Categories

Browse projects by discipline. Each section links to the category index page, which lists
every project in that area. From there you can open individual project pages and see their
lifecycle status badge (`Active`, `POC`, `Deprecated`, `Planned`) and environment
(`Production`, `Non-production`, `Local`).

Use the [Projects by Status](catalog.md) page to filter across all disciplines at once.

## How to navigate

- **By discipline**: pick a category above and browse its index page.
- **By lifecycle status**: go to [Projects by Status](catalog.md) and choose `Active`, `POC`,
  `Deprecated` or `Planned`.
- **By environment**: on the status page, filter by `Production`, `Non-production` or `Local`.
